    Notes

    Integration details

    The frontend uses the same request contract as the backend routes in auth, order tracking, product, and scan.

    The CSRF bootstrap endpoint is exposed at /api/v1/auth/csrf so the browser can obtain a token before sending POST requests.

    Run the frontend through the local proxy server in frontend/server.js to keep the browser same-origin with the API path.
